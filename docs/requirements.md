## 1. プロジェクト概要

### 1.1 コンセプト

Paw Patrol (パウ・パトロール) の世界観を**オマージュ**した、スマートフォン向け3Dタップレースゲーム。
プレーヤーは3人称視点でパトカーを操作し、前方を走る赤いバギー（NPC）を追いかけながら、交差点での方向選択でスコアを稼ぐ。
1分間の制限時間内にハイスコアを目指すシンプルなゲーム性。

### 1.2 著作権に関する方針

- Paw Patrol の公式ロゴ・キャラクター画像は**一切使用しない**
- あくまで世界観（街の雰囲気、色使い、モチーフ）を**オマージュ**する範囲に留める
- キャラクター名をゲーム内UIに表示しない

## 4. ゲームプレイ仕様

### 4.1 基本ルール

| 項目 | 仕様 |
|------|------|
| 制限時間 | **60秒** (スタートから1分) |
| 視点 | **3人称視点** (パトカーの後方上方) |
| 勝利条件 | なし (ハイスコアを競う) |
| 敗北条件 | なし (制限時間終了でゲームオーバー) |

### 4.2 プレーヤー車両 (パトカー)

| 項目 | 仕様 |
|------|------|
| 外観 | 警察車両風の3Dモデル (白/黒ベース、警告灯付き) |
| 速度 | NPCと同等 (20km/h 相当) |
| 操作 | 交差点での方向選択のみ (加減速なし) |

### 4.3 NPC車両 (赤いバギー)

| 項目 | 仕様 |
|------|------|
| 外観 | 赤いバギー風の3Dモデル |
| 速度 | **20km/h** 相当 |
| 走行位置 | プレーヤーの**常に一定距離前方**を走行 |
| 行動パターン | 交差点で**ランダム**に左折・直進・右折を選択 (ただし進行可能な方向からのみ選択) |
| 距離保持 | プレーヤーがミスしても、NPCとの距離は常に一定を保つ |

### 4.4 操作方法 (スマートフォン)

| タップ位置 | 操作 |
|-----------|------|
| 画面左側 (左1/3) | **左折** |
| 画面中央 (中1/3) | **直進** |
| 画面右側 (右1/3) | **右折** |

### 4.5 交差点での判定ロジック

```
交差点3秒前          交差点0.1秒前        交差点到達
    │                     │                  │
    ▼                     ▼                  ▼
────┼─────────────────────┼──────────────────┼────▶ 時間
    │    入力受付期間       │  入力締切        │
    │◀──────────────────▶│                  │
    │                     │                  │
    │  UIに矢印アイコン     │  最後の入力が     │ 結果に応じた
    │  が点滅表示          │  適用される       │ 演出を再生
```

1. **交差点3秒前**: UIに方向指示の矢印アイコン (⬅️⬆️➡️) が点滅表示される
2. **入力受付期間** (3秒前 〜 0.1秒前): プレーヤーはタップで方向を選択可能。複数回入力した場合、**最後の入力が適用**される
3. **交差点0.1秒前**: 入力を締め切る
4. **交差点到達**: 選択された方向に進行し、正解/不正解の判定を行う

#### 入力がなかった場合

交差点到達時に入力がない場合は**直進を適用する**。T字路で直進不可の場合は**不正解扱い**とし、NPCの進んだ方向に自動補正する。

### 4.6 正解時の処理

| 項目 | 仕様 |
|------|------|
| スコア加算 | **+1点** |
| エフェクト | 画面中央から複数の小さな星がキラキラと放射状に飛散 |
| テキスト | 「**Great!**」を画面中央に一時表示 |
| コンボ | なし |

### 4.7 不正解時の処理

| 項目 | 仕様 |
|------|------|
| スコア | 変動なし (減点なし) |
| アニメーション | パトカーが**Z軸で360度スピン** (1回転) |
| スピン所要時間 | **1秒間** |
| 操作制限 | スピン中は**操作不能** |
| 復帰 | スピン後、自動的に**正解ルート (NPCの進んだ方向)** に向かう |

### 4.8 難易度

| 項目 | 仕様 |
|------|------|
| 難易度変化 | **なし** (全時間帯で一定) |
| NPC速度変化 | **なし** (常に20km/h) |
| 判定時間変化 | **なし** (常に3秒前から表示) |

│                      │

### 5.2 HUD要素

| 要素 | 位置 | 詳細 |
|------|------|------|
| タイマー | 画面上部左 | 残り時間をカウントダウン表示 (MM:SS) |

### 5.3 エフェクト

| エフェクト | トリガー | 詳細 |
|-----------|---------|------|
| 星キラキラ + "Great!" | 正解時 | 画面中央から小さな星が放射状に飛散、「Great!」テキストが一時表示 (約1秒) |
| パトカースピン | 不正解時 | パトカーがZ軸360度回転 (1秒間) |

| 項目 | 仕様 |
|------|------|

| 効果音 | **なし** |

## 6. マップ仕様

### 6.1 概要

Paw Patrol の Adventure Bay をオマージュした架空の街。

| 項目 | 仕様 |
|------|------|
| 道路構成 | **ループ状** (街全体を大きく囲む環状道路 + 内部道路) |
| 交差点数 | **約10箇所** |
| 交差点種別 | **十字路** (左・直進・右) および **T字路** (左・右のみ、または2方向のみ) |
| 行き止まり | **なし** (すべての道路が接続され、NPCが行き詰まらない) |
| 外部接続 | **なし** (街の外に向かう道路は存在しない) |

### 6.2 マップ構造 (概念図)

```
              ルックアウトタワー
                    ●
                   / \
                  /   \
     ────●──────●     ●──────●────
    │    農場         市庁舎       │
    │                             │
    ●                             ●  ビーチ
    │                             │
    │         プレイ               │
    ●──────●──グラウンド──●──────●
    │         ●                   │
    │                             │
    ●                             ●  灯台方面
    │    博物館                    │
     ────●──────●─────●──────●────
                  \   /
                   \ /
                    ●
                 レース場
```

- `●` = 交差点 (約10箇所)
- 線 = 道路 (すべて双方向通行)

### 6.3 配置するランドマーク

| ランドマーク | 説明 | 配置条件 |
|-------------|------|---------|
| **ルックアウトタワー** | パウ・パトロールの象徴的な展望台をオマージュしたタワー | **必須配置**。マップ上部の高台に配置 |
| 市庁舎 | 街の行政の中心 | マップ中央〜上部 |
| ビーチ | 海辺のエリア | マップ右側 |
| 灯台 | 海沿いの灯台 | ビーチ付近 |
| 農場 | 動物がいる牧場風の建物 | マップ左側 |
| プレイグラウンド | 遊具のある公園 | マップ中央 |
| 博物館 | 小さな博物館の建物 | マップ下部 |
| レース場 | レーストラック風の広場 | マップ下部 |

### 6.4 道路仕様

| 項目 | 仕様 |
|------|------|
| 車線 | 片側1車線 (対向車なし) |
| 道幅 | パトカー1台分 + 余白 |
| 路面 | アスファルト風テクスチャ |
| 装飾 | 街路樹、歩道、建物を道路脇に配置 |
